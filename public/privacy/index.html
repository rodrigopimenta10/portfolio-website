Privacy Policy

Last updated: September 25, 2026

This policy covers the personal software tools I run for my own job search under the Google Cloud project named Rodrigo Personal Job Search Tools. These are command-line tools that run on my own computer. They are not a product, not a service, and have no users other than me.

Summary: these tools request access to my own Google account only. Data stays on my own machine. Nothing is transmitted to a server I operate, sold, shared, or used for advertising. There is no other user whose data could be collected.

Who this applies to

Only me, Rodrigo Pimenta. The tools authenticate against a single Google account — my own — and are not distributed, hosted, or made available to anyone else. If you have arrived here from an OAuth consent screen, it is because I am authorizing my own software to read my own mailbox and calendar.

What data is accessed

  • Gmail — read access to messages, used to identify job-application status signals such as recruiter replies, interview invitations, and rejections. Also used to apply labels for organizing my own inbox.
  • Google Calendar — read access to events, used to detect upcoming interviews.

No other Google services are accessed. No contact lists are harvested and no messages are sent on my behalf without my explicit action.

How data is stored

OAuth tokens and any cached data are written to local files on my personal computer, in directories excluded from version control. Nothing is uploaded to a database, analytics platform, or third-party service.

How data is used

Solely to organize my own job search — tracking which applications have received replies and when interviews are scheduled. The data is never used for advertising, profiling, resale, or model training, and is never shared with a third party.

Retention and deletion

Local data persists only as long as it is useful to me and can be deleted at any time by removing the local files. Account access can be revoked independently at Google Account permissions, which immediately invalidates the tokens.

Limited Use disclosure

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically: the data is used only to provide the functionality described above, is not transferred to others except as required for that functionality, is not used for advertising, and is not read by any human other than me, the account owner.

Third parties

There are none. The tools run locally and communicate only with Google's APIs and public job-board endpoints. No data is passed to any analytics, advertising, or data-broker service.
